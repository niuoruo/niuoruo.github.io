- 参数类的定义在`arguments/__init__.py`

  此文件首先定义了一个基类：

  ```python
  # `arguments/__init__.py`
  class ParamGroup:
  ```

  这个基类初始化时为传入`parser`并为之添加`group`，便于模块化参数

  ```python
  # `arguments/__init__.py`
  	def __init__(self, parser: ArgumentParser, name : str, fill_none = False):
          group = parser.add_argument_group(name)
  ```
  然后将类内参数一一作为参数写入`group`，这里可能会好奇，明明没定义参数怎么就开始写：这只是个基类，后续重写时会先定义参数再调用基类的`__init__()`

  ```python
  # `arguments/__init__.py`
  	for key, value in vars(self).items():
          shorthand = False
          if key.startswith("_"): # _开头的表示是可以简写的参数，如_resolution用首字母-r也可传入
              shorthand = True 
              key = key[1:]
          t = type(value)
          value = value if not fill_none else None 
          if shorthand:
              if t == bool: # bool类型参数名只要命令行中打出就是True：action="store_true"
                  group.add_argument("--" + key, ("-" + key[0:1]), default=value, action="store_true") 
              else:
                  group.add_argument("--" + key, ("-" + key[0:1]), default=value, type=t)
          else:
              if t == bool:
                  group.add_argument("--" + key, default=value, action="store_true")
              else:
                  group.add_argument("--" + key, default=value, type=t)
  ```
  `__init__()`只是将函数事先声明参数传入`group`，而没有达到保存命令行参数的目的，定义了`extract()`来解决，`extract()`将命令行参数与`__init__()`中声明的参数比对，若在命令行参数在`__init__()`中声明过，将其添加入`GroupParams()`中，返回`GroupParams()`作为该参数类的最终参数：

  ```python
  # `arguments/__init__.py`
      def extract(self, args):
          group = GroupParams()
          for arg in vars(args).items():
              if arg[0] in vars(self) or ("_" + arg[0]) in vars(self):
                  setattr(group, arg[0], arg[1]) # 将参数名为arg[0]，量为arg[1]的参数添加至group
          return group
  ```

  其中`GroupParams()`是个空类，类似一个C语言的结构体，只是用来储存参数：

  ```python
  # `arguments/__init__.py`
  class GroupParams:
      pass
  ```

  下面是模型参数的定义：

  ```python
  # `arguments/__init__.py`
  class ModelParams(ParamGroup): 
  ```

  定义一些模型参数，调用基类`__init__()`写入`group`：

  ```python
  # `arguments/__init__.py`
  	def __init__(self, parser, sentinel=False):
          self.sh_degree = 3
          self._source_path = ""
          self._model_path = ""
          self._images = "images"
          self._depths = ""
          self._resolution = -1
          self._white_background = False
          self.train_test_exp = False
          self.data_device = "cuda"
          self.eval = False
          super().__init__(parser, "Loading Parameters", sentinel)
  ```

  `extract()`中将命令行中的`source_path`转为绝对路径存储：

  ```python
  # `arguments/__init__.py`
      def extract(self, args):
          g = super().extract(args)
          g.source_path = os.path.abspath(g.source_path)
          return g
  ```

- `safe_state()`定义在`utils/general_utils.py`中

  ```python
  # `utils/general_utils.py`

  ```

  首先重写了输出，如果`arg.silent`为`True`，表示静默，不输出任何信息；非静默条件下将`\n`结尾的输出加上时间戳：

  ```python
  # `utils/general_utils.py`
  	old_f = sys.stdout
      class F:
          def __init__(self, silent):
              self.silent = silent
  
          def write(self, x):
              if not self.silent:
                  if x.endswith("\n"):
                      old_f.write(x.replace("\n", " [{}]\n".format(str(datetime.now().strftime("%d/%m %H:%M:%S")))))
                  else:
                      old_f.write(x)
  
          def flush(self):
              old_f.flush()
              
      sys.stdout = F(silent)
  ```

  然后设置了随机种子和设备：

  ```python
  # `utils/general_utils.py`
      random.seed(0)
      np.random.seed(0)
      torch.manual_seed(0)
      torch.cuda.set_device(torch.device("cuda:0"))
  ```
